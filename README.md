# Simple Store Web Application

This repository now includes a very small Flask application for demonstrating a basic online store.

## Running the Store

1. Install dependencies:

```bash
pip install -r requirements.txt
```

2. Start the Flask app:

```bash
python store_app.py
```

The application will be available at `http://localhost:5000`.

Products are hard-coded and users can add or remove items from their session-based cart.
